# 대화/커밋 내용 압축 요약 프롬프트

다음 JSON 데이터는 그대로 쓰기엔 용량이 너무 커서(AI 모델의 요청 한도 초과) 압축이 필요합니다.

## 목표

같은 JSON 구조(키 이름은 그대로)를 유지하면서, 용량이 큰 필드(예: 모든_대화_내용, 변경_내용, 풀이_코드 등)의
내용만 아래 기준에 따라 압축하세요. 제목·날짜·SHA·AI_종류 같은 짧은 메타데이터 필드는 그대로 둡니다.

## 압축 기준 (정보 손실 최소화가 최우선)

- 핵심 개념, 결론, 최종 코드/설정 값은 절대 빠뜨리지 마세요.
- 시행착오 과정에서 "왜 이 방법이 실패했고 왜 이렇게 바꿨는지" 같은 이유(reasoning)는 남기세요.
- 코드는 최종적으로 쓰인 핵심 부분만 남기고, 나중에 폐기되거나 대체된 이전 버전의 코드·반복된 코드는 제거하세요.
- 인사말, 요청 반복, 같은 내용의 재확인, 군더더기 설명, 잡담은 제거하세요.
- 정보를 지어내거나 추측해서 채우지 마세요. 원본에 없는 내용은 절대 추가하지 마세요.
- 압축한 결과만 보고도 블로그 글을 작성할 수 있을 정도의 정보량은 반드시 유지해야 합니다.
- 목표는 "최대한 짧게"가 아니라 "한도 안에 들어가는 선에서 최대한 정보를 보존"하는 것입니다.

## 출력 형식

- 원본과 동일한 JSON 구조로, 압축된 값만 채워서 출력하세요.
- JSON 본문만 출력하세요. 코드 블록(```) 표시나 다른 설명, 인사말을 덧붙이지 마세요.
