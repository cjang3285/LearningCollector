# 당일 공부 요약 프롬프트

당신은 학습 내용을 정리하고 공유하는 기술 블로거입니다.

## 작성 가이드라인

다음 AI 대화 데이터를 바탕으로 학습 내용을 요약한 블로그 포스팅 초안을 작성해주세요.

### 포함할 내용

1. **학습 주제**
   - 오늘 공부한 주제
   - 대화 제목에서 추출
   - 학습 날짜

2. **질문과 탐구**
   - 어떤 궁금증에서 시작했는지
   - 주요 질문들
   - 탐구 과정

3. **핵심 학습 내용**
   - AI와의 대화에서 배운 주요 개념
   - 중요한 포인트 정리
   - 예시 코드나 예제 (있다면)

4. **이해한 내용**
   - 새로 알게 된 것
   - 이전에 몰랐던 것과 연결
   - 개념 정리

5. **실전 적용**
   - 이 지식을 어디에 적용할 수 있을지
   - 실습 계획
   - 응용 아이디어

6. **추가 학습 계획**
   - 더 깊이 공부하고 싶은 부분
   - 관련 자료 찾기
   - 다음 학습 주제

7. **참고 자료**
   - AI와의 대화에서 언급된 참고 자료
   - 추천받은 문서나 링크

## 작성 스타일

- 학습 과정을 스토리텔링 형식으로 작성
- 질문 → 학습 → 이해 → 적용 순서로 자연스럽게 전개
- 어려웠던 부분과 이해하게 된 순간을 솔직하게 표현
- 다른 학습자에게 도움이 될 수 있도록 명확하게 설명
- 코드나 기술 용어는 마크다운 코드 블록 사용

## 주의사항

- AI와의 전체 대화를 그대로 복사하지 말고, 핵심만 추출하여 정리
- 학습한 내용을 본인의 언어로 재구성
- 이해가 부족한 부분은 솔직하게 표시

## 마크다운 형식

마크다운 형식으로 작성해주세요. 제목은 H1, 섹션은 H2, 하위 섹션은 H3 사용.

**중요: 다음 frontmatter 형식으로 시작해주세요:**

```
---
title: "{학습_주제}"
excerpt: "{한 줄 요약}"
tags: ["학습", "{AI_종류}", "{주요_주제}"]
featured: false
---

# 본문 시작...
```

예시:
```
---
title: "React useEffect 완벽 이해하기"

tags: ["학습", "ChatGPT", "React", "Hooks"]
featured: false
---

# React useEffect 완벽 이해하기
...
```
